# История версий и перерисованных отчётов

Перенесено из [`README.md`](../README.md) без изменений.

В паспорте отчётов стоит «v1.0.0 (тег `v1.1.1`)». Первое — строка версии пакета, её не поднимали. Точная версия кода — тег и коммит. Теги с окончанием `-docs` (например, `v1.1.2-docs`) — правки документов и перерисованные отчёты, код в них тот же. После тега `v1.1.1` менялась только печать отчёта (тег `v1.1.2`): основной отчёт стал вдвое короче, полные карточки ушли в файл `*.details.md`. Найденное агентом то же. Отчёты в `reports/` перерисованы из сохранённых результатов командой `python tools/rerender.py reports/report.json -o <папка>/report.md`, модель при этом не вызывалась; в паспорте такого отчёта это сказано в строке «Вёрстка отчёта». Проверка — `python eval/check_same_findings.py`: она сверяет результаты с файлами замера, пересчитывает точность, проверяет, что каждое замечание из JSON есть в отчёте, и показывает, какие файлы кода изменились после `v1.1.1`. Кроме печати менялись документы, шаблон слайдов и результаты замеров, добавлен скрипт разбора результатов `eval/noise_by_stage.py`.
