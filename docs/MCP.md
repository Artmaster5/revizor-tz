# Ревизор ТЗ в чате с ИИ (MCP)

MCP (Model Context Protocol) — это общий «разъём», через который программы вроде Claude Desktop, Cursor и VS Code
вызывают чужие инструменты. Подключив Ревизор ТЗ как MCP-сервер, аналитик пишет в своём чате «проверь это ТЗ»,
чат сам запускает агента и пересказывает результат. Отчёты при этом записываются на диск, как при обычном запуске.
Сервер работает на этом же компьютере, ничего не ставит и не ходит в сеть (кроме обращения к модели, если ключ задан в `.env`).

Нужен только Python 3.10 или новее. Дальше `<путь>` — полный путь к файлу `mcp_server.py` в папке агента.

## Подключение

### Claude Desktop

Файл `claude_desktop_config.json` (меню Settings → Developer → Edit Config):

```json
{
  "mcpServers": {
    "revizor-tz": {
      "command": "python",
      "args": ["/полный/путь/к/mcp_server.py"]
    }
  }
}
```

### Cursor

Файл `.cursor/mcp.json` в проекте (или `~/.cursor/mcp.json` для всех проектов):

```json
{
  "mcpServers": {
    "revizor-tz": {
      "command": "python",
      "args": ["/полный/путь/к/mcp_server.py"]
    }
  }
}
```

### VS Code

Файл `.vscode/mcp.json` в проекте (ключ здесь `servers`, а не `mcpServers`):

```json
{
  "servers": {
    "revizor-tz": {
      "type": "stdio",
      "command": "python",
      "args": ["/полный/путь/к/mcp_server.py"]
    }
  }
}
```

### Windows

В JSON обратную косую черту удваивают (или пишут обычную косую):

```json
{
  "mcpServers": {
    "revizor-tz": {
      "command": "python",
      "args": ["C:\\Users\\Aidar\\revizor\\agent\\mcp_server.py"]
    }
  }
}
```

Если `python` не находится, укажите полный путь к интерпретатору, например `C:\\Python312\\python.exe` (на macOS и Linux — `python3`).
После правки конфигурации перезапустите приложение. Ключи модели берутся из файла `.env`, как у обычного запуска;
без ключей агент работает без модели, только на автоматических правилах.

## Инструменты

| Имя | Что делает |
|---|---|
| `check_requirements` | Проверяет ТЗ (`path` — файл или `text` — текст), пишет отчёты. Необязательно: `provider` (`auto` по умолчанию, `offline` — без модели), `depth` (`full` по умолчанию; `fast` — один проход, быстрее, если чат ограничивает время ответа), `output_dir` (по умолчанию временная папка `revizor-mcp`). Возвращает вердикт, замечания по важности, индекс готовности, главные блокеры, число вопросов и список файлов. |
| `verify_quote` | Проверяет, есть ли цитата (`quote`) в документе, и называет строки. Без модели. |
| `list_checks` | Перечисляет правила, критерии и стандарт проверки. Без модели. |
| `estimate_run` | Оценивает вызовы, токены, стоимость и время, ничего не запуская. |

## Пример разговора

> **Аналитик:** Проверь ТЗ в файле C:\Проекты\Карта\requirements.md, без модели, отчёты положи в C:\Проекты\Карта\reports.
>
> **Чат** (вызывает `check_requirements`): Вердикт — не готово к разработке. Требований 58, замечаний 31
> (CRITICAL 4, MAJOR 17, MINOR 10), индекс готовности 52 из 100. Главные блокеры: D-003 — срок без условий, D-007 — …
> Вопросов автору 9. Отчёт записан в reports\requirements.report.md.
>
> **Аналитик:** Есть ли в документе фраза «не более 2 секунд» и где?
>
> **Чат** (вызывает `verify_quote`): Да, строка 87, раздел «Нефункциональные требования».

## Проверено в настоящем MCP-клиенте

27.11.2026 сервер подключён к Claude Code (MCP-клиент Anthropic) из отдельного файла настроек, без правки общих настроек:

```
claude -p "Вызови verify_quote и list_checks сервера revizor…" --mcp-config mcp_test.json --strict-mcp-config --allowedTools "mcp__revizor__verify_quote,mcp__revizor__list_checks"
```

где `mcp_test.json` — `{"mcpServers":{"revizor":{"command":"<путь к python>","args":["<путь к>/mcp_server.py"]}}}`. Клиент нашёл оба инструмента, вызвал их и пересказал ответы: `list_checks` — 82 правила кода и 8 наблюдений, `verify_quote` — результат поиска цитаты по строкам документа.

MCP — открытый стандарт, поэтому сервер подходит любой программе, которая умеет запускать локальные MCP-серверы. В Cursor и VS Code инструменты агента вызывает та модель, которую выбрал пользователь (GPT, Claude, Gemini и другие).
