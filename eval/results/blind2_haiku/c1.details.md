<a id="x-d-021"></a>
**D-021 · 🟡 MAJOR · Полнота.** Нет экрана для ответа 409 и кнопки «Повторить»

При ответе 409 (по карте уже есть активная заявка) экран не определён: клиент увидит общую ошибку или текст из API, и тестировщик не знает, что ожидать. Не сказано и то, какие параметры отправит повтор.

- Цитата: строка 52
- Как исправить: Указать соответствие ответов и экранов: 409 — экран с текстом «По карте уже оформлена заявка»; 401 — переход на вход; 404 — текст «Карта не найдена»; 500 — экран «Не удалось оформить заявку». Кнопка «Повторить» повторяет запрос с теми же параметрами.
- См. также (место из объединённого повтора, на отметки не влияет): строка 93: «Идемпотентность запроса не требуется: повторный запрос по той же карте будет отклонён по правилу Ф-2»
- Объединено с похожими замечаниями: «Повтор после ошибки 500 конфликтует с правилом «повтор отклоняется»»
- Источник: модель

<a id="x-d-026"></a>
**D-026 · 🟡 MAJOR · Однозначность.** Критерий «ближайшее» отделение не задан

Разработчик может выбрать отделение по прямой, а тестировщик по маршруту. Клиенту могут назначить разные отделения, и тесты будут давать разные ожидаемые результаты.

- Цитаты:
  - строка 53
  - строка 47: «для отделения — список отделений из справочника»
- Как исправить: Указать способ измерения расстояния (по прямой по координатам, по маршруту или по времени в пути) и источник координат отделений.
- Объединено с похожими замечаниями: ««Ближайшее к адресу доставки отделение» не определено»; «Критерий «ближайшее отделение» не определён»
- Вопрос автору [В-17](#x-v-17); источник: модель
