# Шот бойынша үзінді көшірмені мобильді банкте қалыптастыру және жіберу

### Жалпы мәліметтер

| Өріс | Мәні |
| :--- | :--- |
| **Тапсырманың атауы** | Шот бойынша үзінді көшірмені PDF форматында қалыптастыру, сақтау және электрондық поштаға жіберу |
| **Өнім** | Жеке тұлғаларға арналған мобильді банк |
| **Бизнес-процесс** | Клиенттерге ақпараттық қызмет көрсету |
| **Business owner** | Бөлшек бизнес департаменті |
| **Product owner** | Цифрлық арналар басқармасы |
| **Талдаушы** | Жүйелік талдау бөлімі, «Шоттар» командасы |
| **Жұмыс түрі** | Жаңа функционал |
| **АЖ-ға әсері** | Мобильді банк, АБЖ, құжаттарды қалыптастыру сервисі (DocService), пошта сервисі (MailService) |
| **JIRA-дағы тапсырма** | STMT-311 |
| **Құжат нұсқасы** | 1.0, 18.11.2026 |

### Мақсаты
Қазір клиент үзінді көшірме алу үшін бөлімшеге барады немесе байланыс орталығына хабарласады: айына орта есеппен
12 000 өтініш түседі. Мақсат — 2027 жылғы 1 наурызға дейін осы өтініштердің кемінде 60 %-ын мобильді банкке көшіру.

### Терминдер
| Термин | Анықтамасы |
| :--- | :--- |
| Үзінді көшірме | Таңдалған кезеңдегі шот бойынша операциялар тізімі және кезең басындағы, соңындағы қалдық көрсетілген құжат |
| Кезең басындағы қалдық | `dateFrom` күні сағат 00:00:00-дегі шот қалдығы |
| Кезең соңындағы қалдық | Кезең басындағы қалдыққа кезеңдегі түсімдерді қосып, есептен шығаруларды алғандағы сома |

Құжаттағы барлық күн мен уақыт Алматы уақытымен (UTC+5) көрсетілген.

### Шешім архитектурасы
Мобильді қосымша → API-шлюз → StatementService → АБЖ (операциялар мен қалдықтар).
StatementService → DocService (PDF) → MailService (электрондық пошта).

### UI процесінің дизайны
Шоттар → шот карточкасы → «Үзінді көшірме». Экранда: кезеңді таңдау (бастапқы және соңғы күн), тілді таңдау,
«Қалыптастыру» және «Поштаға жіберу» батырмалары.

### Функционалдық талаптар
* **Ф-1.** Клиент өзіне тиесілі кез келген ашық шот бойынша, сондай-ақ соңғы 3 жыл ішінде жабылған шот бойынша үзінді көшірме сұрай алады. Функция теңгедегі, шетел валютасындағы және мультивалюталық шоттар үшін қолжетімді.
* **Ф-2.** Үзінді көшірменің кезеңі соңғы 3 жылдың ішінде болуы тиіс, бір сұраныстағы кезең ұзақтығы — 12 айдан аспайды.
* **Ф-3.** Кезеңнің басталу және аяқталу күндерінің шекаралары клиенттің құрылғысындағы уақыт бойынша анықталады.
* **Ф-4.** Үзінді көшірмеге кезең ішіндегі шот бойынша барлық операциялар енгізіледі.
* **Ф-5.** Үзінді көшірме PDF файлы түрінде қалыптастырылып, банктің электрондық цифрлық қолтаңбасымен (ЭЦҚ) қол қойылады. Қол қою тәсілін жобалау кезеңінде ақпараттық қауіпсіздік департаменті айқындайды.
* **Ф-6.** Клиент дайын үзінді көшірмені қосымшада ашып, телефонға сақтай алады. Электрондық поштаға үзінді көшірме тек клиенттің банк профилінде расталған мекенжайына жіберіледі.
* **Ф-7.** Үзінді көшірме тілі — қазақ, орыс немесе ағылшын тілі. Тілді клиент таңдайды, әдепкі бойынша қосымшаның интерфейс тілі қолданылады.
* **Ф-8.** PDF файлы сапалы және оқуға ыңғайлы болуы керек.
* **Ф-9.** Файлдың жоғарғы сол жақ бұрышында банк логотипі 40×40 px өлшемде орналасады, мәтін Roboto қаріпімен 10 pt өлшемде жазылады.
* **Ф-10.** Бір клиент тәулігіне 10 үзінді көшірмеден артық сұрай алмайды. Лимит Алматы уақытымен 00:00-де жаңарады.
* **Ф-11.** Дайын файлға сілтеме 30 күн бойы жарамды, одан кейін файл StatementService қоймасынан жойылады.
* **Ф-12.** Клиент өз шоты бойынша үзінді көшірмені PDF форматында ала алады.

### Функционалдық емес талаптар
* 12 айлық кезеңге арналған PDF файлы сұраныстардың 95 %-ында 5 секундтан аспай қалыптастырылады (секундына 20 сұраныс жүктемесінде).
* Үзінді көшірмелер мен сілтемелер Қазақстан аумағындағы банк серверлерінде ғана сақталады.

### Деректерге қойылатын талаптар
`statement_request` кестесі: `id`, `client_id`, `account_id`, `date_from`, `date_to`, `lang`, `email`, `status`
(`READY`, `SENT`, `FAILED`), `file_key`, `created_at`, `expires_at`. Жазбалар 5 жыл сақталады.

### Интеграцияға қойылатын талаптар
Операциялар мен қалдықтар АБЖ-ның `GetAccountTransactions` әдісі арқылы алынады (ABS-API v3.2, 7-бөлім).
Хат MailService арқылы жіберіледі, PDF хатқа тіркеме ретінде қосылады.

## REST API

### Жалпы параметрлер

| Өріс | Мәні |
| :--- | :--- |
| **Description** | Үзінді көшірмені қалыптастыру және қажет болса электрондық поштаға жіберу |
| **REST type** | GET |
| **Authorization** | Bearer, шот иесінің сессиясы |
| **Controller** | StatementController |
| **Request URL** | `/api/v1/accounts/{accountId}/statements/create` |

### Әдістің жұмыс логикасы
1. Сессияны және шоттың клиентке тиесілі екенін тексеру.
2. Кезеңді және тәуліктік лимитті тексеру.
3. АБЖ-дан операциялар мен қалдықтарды алу, DocService арқылы PDF қалыптастыру.
4. `email` параметрі берілсе, файлды осы мекенжайға MailService арқылы жіберу.
5. Файлға сілтемені және оның жарамдылық мерзімін қайтару.

### Сұраныс параметрлері

#### Path-параметрлер
| Parameter | Format | Mandatory | Description |
| :--- | :--- | :--- | :--- |
| `accountId` | string, 1–32 | Иә | Шоттың АБЖ-дағы идентификаторы |

#### Query-параметрлер
| Parameter | Format | Mandatory | Logic | Description |
| :--- | :--- | :--- | :--- | :--- |
| `dateFrom` | string, `YYYY-MM-DD` | Иә | `dateFrom` ≤ `dateTo` | Кезеңнің басталу күні, қоса есептеледі |
| `dateTo` | string, `YYYY-MM-DD` | Иә | `dateTo` − `dateFrom` ≤ 6 ай | Кезеңнің аяқталу күні, қоса есептеледі |
| `lang` | string | Жоқ | `kk` / `ru` / `en` | Үзінді көшірме тілі |
| `email` | string, ≤ 254 | Жоқ | RFC 5322 | Файл жіберілетін мекенжай |

### Жауап
| Parameter | Format | Description |
| :--- | :--- | :--- |
| `statementId` | string | Үзінді көшірме идентификаторы |
| `accountId` | integer | Шот идентификаторы |
| `currency` | string, ISO 4217 | Шот валютасы |
| `fileUrl` | string | PDF файлына сілтеме |
| `expiresAt` | string, ISO 8601 | Сілтеменің жарамдылық мерзімі |

### Статустар
**200.** Үзінді көшірме қалыптастырылды.
**400.** Кезең қате көрсетілген: `{"code":"INVALID_PERIOD"}`.
**401.** Сессия жоқ немесе мерзімі өткен.
**404.** Шот табылмады. Басқа клиенттің шоты үшін де 404 қайтарылады, шоттың бар-жоғы ашылмайды.
**429.** Тәуліктік лимит асып кетті: `{"code":"DAILY_LIMIT"}`.
**500.** Ішкі қате; файл қалыптастырылмайды.

### Тестілеуге қойылатын талаптар
Ф-1–Ф-11 бойынша функционалдық тест-кейстерді тестілеу командасы 10.12.2026-ға дейін дайындайды. Жүктемелік тестілеу
функционалдық емес талаптардағы көрсеткіштермен жүргізіледі. Тест ортасында АБЖ-ның тестілік шоттары қолданылады.

### Қабылдау критерийлері

| Бастапқы шарттар | Әрекет | Күтілетін нәтиже |
| :--- | :--- | :--- |
| Теңгелік шот, 01.11.2026–30.11.2026 кезеңінде 25 операция | Үзінді көшірме қалыптастыру | 200, PDF-те 25 операция, басындағы және соңындағы қалдық |
| Операция 30.11.2026 сағат 23:40-та | 01.11.2026–30.11.2026 кезеңін сұрау | Операция үзінді көшірмеге енеді |

| Басқа клиенттің шоты | Сұраныс | 404 |
