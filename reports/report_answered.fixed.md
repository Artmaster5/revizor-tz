# Предлагаемые формулировки для «requirements.md»

Черновики исправленных требований: написанные проверяющим без решения автора и учитывающие ответы автора. Перед внесением в документ их должен прочитать автор: модель могла ошибиться.

Проверка смысла: предложено формулировок 26, напечатано 11, не напечатано 15. Формулировка печатается, только если она описывает то же требование, не теряет числа, коды и идентификаторы исходного текста, не сокращает его правила и не вносит значений, которых нет в документе и в ответах автора.
