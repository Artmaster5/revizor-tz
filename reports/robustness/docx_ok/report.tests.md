# Черновики приёмочных тестов для «good.docx»

Ожидаемый результат взят только из документа. Черновик печатается, только если в нём есть конкретное действие и конкретный ожидаемый результат; придумывать поведение за автора агент не вправе. Это черновики для тестировщика, не готовые тест-кейсы.

Готовы к прогону: 3. Ждут ответа автора: 0. Нельзя проверить, пока нет ответа: 1 (список в конце файла).

### Т-01 · позитивный · REQ-006

**2.3: если номер получателя не найден** — готов

- **Дано:** Система работает в обычном режиме, данные для сценария подготовлены.
- **Когда:** Создать условие: номер получателя не найден.
- **Тогда:** Система должна предложить отправить приглашение (требование 2.3).

### Т-02 · граничный · REQ-010

**3.2: граничные допустимые значения 5** — готов

- **Дано:** Система работает в обычном режиме; проверяется требование 3.2: «Все операции записываются в журнал аудита и хранятся не менее 5 лет».
- **Когда:** Ввести или передать значения на границе допустимого: 5. (шаг значения не задан: взяты соседние целые.)
- **Тогда:** Значения принимаются без ошибки: по требованию 3.2 допустимо «не менее 5».

### Т-03 · граничный · REQ-010

**3.2: значения сразу за границей 4** — готов

- **Дано:** Система работает в обычном режиме; проверяется требование 3.2: «Все операции записываются в журнал аудита и хранятся не менее 5 лет».
- **Когда:** Ввести или передать значения сразу за границей: 4. (шаг значения не задан: взяты соседние целые.)
- **Тогда:** Значения не принимаются как допустимые: по требованию 3.2 допустимо только «не менее 5».

## Что нельзя проверить, пока нет ответа

Для этих требований в документе нет конкретного действия или ожидаемого результата, поэтому черновик теста не составлен.
