# Витрина устойчивости

Запуск одной командой: `python tools/robustness.py`

Агент запускается как есть, без ключей и без модели (только 82 автоматических правила), на файлах, которые на практике приходят битыми или неподходящими. Файлы скрипт каждый раз создаёт заново. Рядом с таблицей лежат отчёты и вывод консоли по каждому случаю.

| Вход | Что сделал агент | Код выхода | Время, с |
| --- | --- | --- | --- |
| Пустой файл (0 байт) | сказал «Файл пустой» и не стал выдумывать оценку | 0 | 0.2 |
| Двоичный мусор под видом .md | сказал «Файл не похож на текстовый документ» и не стал выдумывать оценку | 0 | 0.2 |
| PDF с паролем | сказал «PDF защищён паролем» и не стал выдумывать оценку | 0 | 0.3 |
| PDF без текстового слоя (как скан) | сказал «В PDF нет текстового слоя — похоже на скан» и не стал выдумывать оценку | 0 | 0.3 |
| Целый минимальный DOCX с ТЗ | отчёт: требований 10, замечаний 3, индекс 95, вердикт CONDITIONAL | 0 | 0.3 |
