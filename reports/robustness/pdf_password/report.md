## Документ не проверен

**Что случилось.** Текст в файле зашифрован, без пароля его прочитать нельзя.

**Что это значит.** Агент не смог получить из файла текст требований, поэтому ни правила, ни модель его не проверяли. Вердикт не выносится.

**Что сделать:**

1. Попросите автора прислать версию без пароля.
2. Или откройте файл с паролем и сохраните копию без защиты, затем повторите проверку.
